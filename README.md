# 🚑AUXILIO 🚨 HOSPITO🏥
## Problem Statement
In emergency medical situations, patients often face delay and confusion when trying to avail ambulance services and hospital care. Currently, there is no unified system that allows the users to:
<ul>
  <li>Book ambulances</li>
  <li>Access reliable information about ambulance, hospital and emergency services</li>
  <li>Share patient data with hospitals in prior</li>
  <li>Understand the waiting time and priority on arrival</li>
</ul>
At the same time, hospital find it difficult to manage due to:
<ul>
  <li>Inefficient patient intake processes</li>
  <li>Lack of pre-arrival patient information</li>
  <li>Poor queue management based on the severity</li>
</ul>
These challenges result in delayed treatment, increased stress and inefficient use of medical resources which can severely impact patient outcomes. 

## Key Features
Our project comprises of 2 parts – Auxilio and Hospito
<ul>
  <li>Auxilio: An Ambulance Booking Platform that allows the users to book, track and share emergency details.</li>
  <li>Hospito: A hospital management system that uses the shared data to prioritize and streamline patient care. </li>
</ul>
Another key feature being, admin-based access for patient and doctors.

## Steps to Run
<ul>
  <li>Create a database named hospito_db in MySQL</li>
  <li>In application.properties (\hospito\src\main\resources) replace with your MySQL password.</li>
  <li>Run using spring-boot:<br>1. mvn clean install<br>2. mvn spring-boot: run</li>
</ul>
